# 💰 Python Capstone - Expense Tracker (Flask)

A complete Flask web application to track daily expenses built for Codomax Digital Internship.

## 🚀 Features
- Add / Delete expenses
- View total spending
- SQLite database storage
- Logging system for debugging
- Clean UI with Flask templates

## 🛠️ Tech Stack
Python, Flask, SQLite, HTML/CSS, Gunicorn

## ▶️ How to Run
pip install -r requirements.txt
python app.py
